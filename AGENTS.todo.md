# Backlog & Task Management

## Offene Punkte

### Phase 8: E2E Testing Strategy (Playwright)
- [ ] **E2E: Page Object Model (POM) Setup**: Erstelle einen `helpers` Ordner für Playwright und lagere den Login-Prozess in eine wiederverwendbare `loginAs(role)` Funktion aus.
- [ ] **E2E: Component Helpers**: Erstelle Helper-Klassen für wiederkehrende UI-Elemente (z.B. `SidebarHelper` zum Navigieren, `ModalHelper` für Formulare), um die Tests lesbar zu halten.
- [ ] **E2E: Photographer Workflow II (Upload & Edit)**: Teste das Aufrufen einer Galerie, Mocke einen Datei-Upload (Drag & Drop UI) und das anschließende Ändern der Galerie-Einstellungen.
- [ ] **E2E: Client Workflow (Selection)**: Teste den Aufruf eines Magic Links, die Eingabe von Name/E-Mail, das Setzen von Sternen/Kommentaren an einem Bild und den Klick auf "Auswahl abschließen".
- [ ] **E2E: Client Workflow (Delivery)**: Teste den Gast-Zugriff auf eine finale Galerie und verifiziere, dass die Download-Buttons für Einzelbilder und ZIPs sichtbar und klickbar sind. Prüfe, dass keine Edit-Buttons sichtbar sind.
- [ ] **E2E: Admin Workflow (User & Settings)**: Teste das Anlegen eines neuen Fotografen-Accounts, das Vergeben von Rechten sowie das Speichern von Wasserzeichen-Einstellungen.
- [ ] **E2E: Guest Workflow (Public Search)**: Teste die Suche als anonymer Nutzer, stelle sicher, dass nur öffentliche Galerien gefunden werden und die Navigation dorthin klappt.
